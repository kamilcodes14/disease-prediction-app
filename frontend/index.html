Method

What's actually running under the hood

Three classifiers are trained on real, public medical datasets — Logistic Regression, an RBF Support Vector Machine, Random Forest, and XGBoost are each evaluated on a held-out test split, and the strongest performer by ROC-AUC is the one serving predictions.

Photo screening — added capability

An honest note on the image feature

There's no ethically-sourced, labeled clinical imaging dataset used here — so instead of faking a deep learning model, the photo screening pipeline extracts real, measurable image features (color variegation, edge/border irregularity, texture entropy, left-right and top-bottom asymmetry) and classifies with a Random Forest. It's a genuine, working computer-vision pipeline, built around the same ABCD rule dermatologists are taught — but it is a portfolio prototype, not a validated diagnostic device. Swap in a real labeled dataset (e.g. HAM10000 / ISIC) before this ever informs a real decision.
